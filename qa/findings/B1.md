refaite dans pgAdmin pour corriger l'event_id :

```sql
    SELECT 
        c.name, 
        c.quota, 
        SUM(oi.quantity) AS reserves 
    FROM ticket_categories c
    JOIN order_items oi ON oi.category_id = c.id 
    JOIN orders o ON o.id = oi.order_id 
    WHERE 
        o.event_id = (select o.event_id from orders o order by created_at desc limit 1) AND
        o.status IN ('pending', 'paid') 
    GROUP BY c.name, c.quota;
```
